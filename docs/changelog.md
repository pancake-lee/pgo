# Changelog

> 版本历史，面向用户描述新增/修复/移除的内容。

## [0.0.9] - 2024-09-30

### Added

- 实现"一个用户可以加入多个部门，在不同部门里分别担任不同的职位"

## [0.0.8] - 2024-06-17

### Added

- 新增 genCURD：通过 ORM 结构体生成基础 CURD 代码
- 生成 4 个表对应的 CURD 代码，覆盖从接口到数据库的完整链路

## [0.0.7] - 2024-06-14

### Added

- 新增用户职位的 CURD 接口

## [0.0.6] - 2024-04-16

### Added

- 新增 API：注册、登录、获取用户列表、删除用户、修改名称
- 整理项目文件，定义接口，实现接口，编写测试代码
- 分离逻辑层代码，api 定义、db 连接及 model 等公用

## [0.0.5] - 2024-04-14

### Added

- pg 使用 docker-compose 运行，参数记录于 gogogo.yaml，实际数据映射到宿主机
- 连接 pg，创建 user 表
- 用 gorm-gen 工具生成数据库访问代码，记录于 makefile 的 gorm 目标
- Windows 下 make 的安装记录
- 在 demo 中测试对数据库 user 表的访问

## [0.0.4] - 2024-04-12

### Removed

- 移除 config 相关结构体：配置保持简单，弃用 yaml 改用 ini
- 移除 wire：理念认同但不够通用，会给协作带来额外成本
- 移除一些对象封装：代码总量不多，与其分散不如汇聚

## [0.0.3] - 2024-04-12

### Added

- 初始化 kratos 官方模板工程

### Removed
