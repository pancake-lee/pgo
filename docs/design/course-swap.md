# 换课功能设计

> 状态：已完成

## 需求背景

教师之间经常需要换课，需要一个工具来辅助找到合适的换课对象并记录换课情况。

## 核心概念

需要区分两个视角的数据：

- **课程表**（班级视角）：每周一致，某个[班][周几]第几节上什么课
- **课程安排**（教师视角）：某个[老师][某天]第几节上什么课，换课操作的是教师之间的课程安排

## 功能设计

### 换课条件

找到可换的 B 课堂需要满足：
1. B 课堂时间，本班老师没有课
2. A 课堂时间，我自己没有课
3. 需要结合已经换过的课来判断以上两条

### 欠课机制

- 可以选择不立即指定 B 课堂，则记为欠课（欠条）
- 欠课归还时，回填 B 课堂

### 数据流

```
Excel 课程表 → 解析 → 计算未来课程安排（默认 3 周）
                      → 结合已有换课/欠课记录
                      → 计算候选 B 课堂
                      → 用户选择并提交换课记录
```

- 课程表不保存到数据库，每次读取最新 Excel
- 换课记录写入数据库

### 查询功能

- 查询某个老师未来的课程安排
- 查询某个班未来的课程安排
- 查询某个老师的换课、欠课列表

## 实现分工

| 端 | 职责 |
|----|------|
| 服务端 | 换课记录 CURD |
| 客户端 | 读取课程表、计算课程计划、找到可换的课、提交换课记录 |

客户端 SDK 通过 swagger-codegen 从 OpenAPI 规范自动生成。
