# v0.0.10 版本归档

> 归档日期：2026-09-29。

## 本版范围

- 代码生成：以 Proto option 管理 genCURD 表归属映射，并完善失败回滚与隔离回归。
- 质量门禁：恢复离线全量测试与静态检查，隔离真实外部依赖测试。
- 构建与 CI：修正构建元数据，建立统一离线质量检查和 GitHub Actions 验证。

## 完成事项

### 14. genCURD Proto 表归属映射

- 新增 `pgo.tables` 服务 option，以 Proto 声明作为表到服务的唯一映射来源。
- 未映射表自动进入 default service，并输出迁移说明、服务映射摘要和待归属提示。
- 增加重复映射、未知表和映射迁移等离线回归。

### 17. 全量测试与静态检查恢复

- 修正 JWT 测试的认证上下文构造，并覆盖缺失 claims。
- 修正日志包装器的动态格式串问题，恢复 `go test ./...` 和 `go vet ./...` 门禁。

### 18. 外部依赖测试隔离

- 将依赖 APITable、Redis、企业微信和业务数据库的测试划入 `integration` 标签。
- 增加显式集成测试入口和前置条件检查，默认离线测试不再依赖本地配置或外部服务。

### 19. genCURD 生成失败回滚

- 为 DAO、Proto、API 和 OpenAPI 生成产物建立快照、提交与回滚边界。
- 失败时恢复原产物并清理本轮新增文件，成功后才清理过期生成文件。

### 20. 构建元数据修正

- 统一构建目标的版本、提交号和 UTC 构建时间注入方式。
- Git 信息不可用时使用明确的 `unknown` 占位值，避免生成不可追溯的空元数据。

### 21. P0 生成链路回归与 CI

- 为 genCURD、genGORM 和 sheet2mysql 增加隔离 fixture 回归。
- `make test` 统一执行默认离线测试和静态检查，GitHub Actions 在 push 和 pull request 时执行质量门禁与构建。

## 验证记录

- 2026-09-29：`GOTOOLCHAIN=local make build` 通过，产物输出到 `bin/`。
