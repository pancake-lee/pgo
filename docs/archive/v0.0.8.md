# v0.0.8 版本归档

> 归档日期：2026-09-07。

## 本版范围

- 核心框架：组织架构树、genCURD 代码生成、任务管理后端。
- 客户端：教师换课与欠课管理。
- 基础设施：嵌套事务、独立 pprof 诊断端口与持续监控。
- 应用框架：请求追踪、请求标识与 `AppCtx` 请求元数据。

## 完成事项

### 1. 组织架构树

- 支持用户加入多个部门，并在各部门分别承担职位。

### 2. genCURD 代码生成工具

- 根据 ORM 结构体生成接口、服务与数据访问的基础 CRUD 链路。

### 3. 换课功能

- 覆盖课程表解析、候选课堂计算、换课记录 CRUD，以及教师换课/欠课管理。

### 4. 任务管理后端

- 提供任务表的 CRUD 接口，支持树形结构与表格视图。

### 12. pprof 性能分析

- 增加默认关闭的独立诊断端口，pprof 由 `Diagnostics.Pprof` 单独启用。
- 增加 `pgo diagnostics profile {cpu|heap|goroutine}`，支持拉取 profile 和 `--open` 查看。

### 13. 持续监控

- 提供应用请求量、错误率、耗时指标，以及 MySQL、Redis、RabbitMQ 健康状态。
- 增加 Prometheus 抓取与告警规则、Grafana 应用仪表板、健康与指标 CLI 查询入口。

### 15. AppCtx 中间件能力增强

- HTTP/gRPC 自动接入 tracing 与请求标识中间件，响应返回 `X-Request-ID`。
- `AppCtx` 增加 `TraceID`、`StartTime`、`Elapsed` 和 `LogElapsed`。

### 18. 嵌套事务

- 实现按事务 ID 管理的嵌套事务，内层复用真实事务，任意层回滚整体回滚。
- 支持 `defer rollback` 惯用模式，并自动让查询对象使用当前事务。

## 验证记录

- 监控、诊断和 AppCtx 定向单测通过。
- `pgo` CLI 构建通过，诊断命令可用。
- 全量测试受既有本地环境依赖影响，缺少 `configs/pancake.yaml`，部分数据库、第三方服务和 JWT 既有测试未通过。

## 遗留事项

- 14：genCURD `inferServiceName` 配置化。
- 16：genCURD 支持多主键表。
